# Dars 26: Document va Window Parametrlari

**Davomiyligi:** 19:54

## 📋 Dars mazmuni

Bu darsda Document va Window obyektlarining parametrlarini o'rganamiz:
- Document obyekti xususiyatlari
- Window obyekti xususiyatlari
- Browser parametrlari
- Screen va viewport ma'lumotlari

## 🎯 O'rganiladigan mavzular

### Document Parametrlari
- document.documentElement
- document.body
- document.head
- document.title
- document.URL
- document.domain

### Window Parametrlari
- window.innerWidth va innerHeight
- window.outerWidth va outerHeight
- window.screenX va screenY
- window.location
- window.history

### Screen Parametrlari
- screen.width va screen.height
- screen.availWidth va availHeight
- screen.colorDepth
- screen.pixelDepth

### Viewport Parametrlari
- Viewport o'lchamlari
- Scroll position
- Element position
- Responsive design
