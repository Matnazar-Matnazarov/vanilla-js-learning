📄 Dars 26: Document va Window Parametrlari

📋 Dars mazmuni: Document va Window obyektlarining parametrlarini o'rganish, Browser parametrlari, Screen va viewport ma'lumotlari. Browser konsolni oching (F12) va natijani ko'ring.

🎯 Demo maydoni

Quyidagi maydon parametrlar ko'rsatish uchun ishlatiladi:

📄 Document Parametrlari

document.documentElement, document.body, document.head, document.title, document.URL, document.domain

🪟 Window Parametrlari

window.innerWidth, window.outerWidth, window.location, window.history, window.screenX, window.screenY

🖥️ Screen Parametrlari

screen.width, screen.height, screen.availWidth, screen.availHeight, screen.colorDepth, screen.pixelDepth
