# Vanilla JavaScript Learning Course

## 📚 Kurs haqida

Bu kurs JavaScript dasturlash tilini noldan o'rganish uchun tayyorlangan professional o'quv materialidir. Kursda JavaScript asoslari, DOM manipulyatsiyasi, hodisalar bilan ishlash va boshqa muhim mavzular qamrab olinadi.

## 🎯 Kurs maqsadi

- JavaScript dasturlash tilining asosiy tushunchalarini o'zlashtirish
- Praktik loyihalar orqali bilimlarni mustahkamlash
- Real loyihalarda qo'llash imkoniyatiga ega bo'lish
